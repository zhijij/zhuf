# 使用时机

当用户要求总结聊天、梳理当前业务、提取下一步动作、生成沟通回复或判断进度时使用。

# 摘要重点

- 租户：预算、入住时间、看房时间、顾虑、合同问题。
- 户主：房源补充、委托状态、客户反馈、签约风险。
- 中介：客户等级、跟进节点、复看/签约安排、无效原因。
- 审核员：审核结论、证据、驳回原因、需补充字段。

# 边界

- 聊天记录只能作为上下文和证据线索。
- 不替代合同、审核结论或业务数据库真实状态。

# 输出要求

用短段落给出当前进度、关键分歧和下一步动作；话术要能直接复制到聊天模块。
