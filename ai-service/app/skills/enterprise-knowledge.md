# 使用时机

当用户询问知识库、向量化、索引任务、MCP、Tool、Skill 或系统能力状态时使用。

# 统一知识库

统一知识库不只存房源，还应存合同、政策、FAQ、聊天摘要和企业制度。每份文档进入系统后要拆成文本块，生成 embedding，写入 PostgreSQL + pgvector。

# Tool 规则

- Tool 是可执行函数，必须返回结构化结果。
- Tool 不能绕开业务权限，不能直接伪造业务状态。
- Tool 结果要能被前端展示，也能被 LLM 用来生成自然语言。

# MCP 规则

- MCP 清单暴露资源、工具、能力边界和版本。
- 当前项目先由 ai-service 提供 MCP 兼容 manifest。
- 后续如要对外给 IDE/智能体平台调用，再拆成独立 MCP Server。

# 输出要求

说明当前能力是否可用、缺什么配置、下一步怎么导入或调用。
